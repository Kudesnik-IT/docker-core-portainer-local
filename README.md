# Portainer CE Stack (Local)

Docker Compose стек для развертывания локальной панели управления Portainer CE с прямым подключением к Docker API.

## Архитектура и безопасность

* Панель использует прямое подключение к `/var/run/docker.sock` с правами на запись (`rw`) для полноценного управления ресурсами текущего сервера.
* Контейнер работает с ограничениями: `read_only: true`, `cap_drop: [ALL]`, `no-new-privileges: true` и жесткими лимитами CPU/RAM/PIDs.
* Для предотвращения переполнения диска используется драйвер `local` для ротации логов.

## Требования

* Docker Engine >= 24.0
* Docker Compose >= 2.0

## Быстрый старт

### 1. Загрузка репозитория в директорию со стеками:
```bash
git clone <URL_репозитория> /opt/stacks/core-portainer-local
cd /opt/stacks/core-portainer-local

```

### 2. Подготовка файла окружения:

```bash
cp .env.example .env
chmod 600 .env
nano .env

```

Обязательно укажите внутренний IP-адрес интерфейса сервера в переменной `HOST_IP`.

### 3. Запуск стека:

```bash
docker compose up -d

```

Веб-интерфейс будет доступен по адресу `https://<HOST_IP>:<PORTAINER_HTTPS_PORT>`.

### 4. Инициализация и получение токена:

Откройте веб-интерфейс по адресу `https://<HOST_IP>:<PORTAINER_HTTPS_PORT>`.
Создание первой учетной записи администратора должно быть выполнено в течение 5 минут после старта. Для подтверждения прав система запросит токен безопасности.
Получите его из логов контейнера:

```bash
docker compose logs portainer | grep setup_token

```

Скопируйте хэш после `setup_token=` в форму инициализации и задайте пароль.
*(Примечание: если 5-минутный интервал истек, доступ будет заблокирован. Для сброса таймера выполните `docker compose restart portainer`).*

## Права доступа

**Внимание:** Данная конфигурация использует прямое подключение к сокету Docker без промежуточной фильтрации. Панель обладает полными административными правами на создание, редактирование и удаление контейнеров, сетей и томов на этом сервере. Ограничьте сетевой доступ к порту панели и используйте надежные пароли.

## Обслуживание

Обновление версии образа:

1. Изменить тег `PORTAINER_IMAGE` в файле `.env`.
2. Выполнить:

```bash
docker compose pull
docker compose up -d

```
